**Manhunt** was developed for a mobile application development course as an exploration into advanced mobile architecture, real-time tracking, and interactive pursuit mechanics. The core experience challenges players to navigate spatial tracking and dynamic movement using mobile input interfaces to manage active chase scenarios.

## Core Technical & Design Elements

1. **Advanced Mobile Architecture**: Structured robust application components to handle asynchronous events and maintain system stability under active usage.
2. **Real-Time Tracking**: Implemented underlying state logic and tracking features to monitor player positioning and update interactive pursuit states dynamically.
3. **Course Project Scope**: Engineered and refined within an academic curriculum to meet rigorous mobile development and design standards.

## Final Result

Manhunt successfully demonstrates sophisticated mobile software architecture combined with engaging real-time tracking mechanics.
