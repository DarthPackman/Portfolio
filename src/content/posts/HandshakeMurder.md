**Handshake Murder** was developed for **COMP 2160, Mobile App Development 1** (Winter 2022) as an exploration into mobile-focused mechanics and interactive deduction gameplay. The core experience challenges players to navigate social deduction elements, utilizing mobile input interfaces to manage hidden identities and stealth actions.

## Core Technical & Design Elements

1. **Mobile Interaction Design**: Built responsive touch controls and user interface elements optimized for mobile form factors.
2. **Deduction Mechanics**: Implemented underlying state logic to manage secret roles, player tracking, and victory conditions.
3. **Course Project Scope**: Structured and engineered within the academic timeline of a foundational mobile development curriculum.

## Final Result

Handshake Murder successfully demonstrates core mobile application architecture combined with engaging social deduction mechanics.

You can view the source code and project repository [here](https://github.com/DarthPackman/Handshake-Murder).
